# ฝากจำ

> ไม่ต้องจำทุกเรื่อง แค่จำไว้ว่าฝากไว้ที่นี่

แอปช่วยจำสำหรับมือถือ ส่งรูปหรือข้อความ → ตรวจสิ่งที่แอปเข้าใจ → เตือนพร้อมสิ่งที่ต้องใช้ → ค้นคืนได้

## ขั้นที่ 1 — ขึ้น GitHub Pages (ใช้ได้ทันที)

1. สร้าง repo ใหม่ เช่น `fakjam`
2. อัปโหลด `index.html`, `manifest.json`, `sw.js` และโฟลเดอร์ `icons/`
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที เปิด `https://<ชื่อคุณ>.github.io/fakjam/`

ตอนนี้แอปใช้ได้แล้วในโหมดพื้นฐาน:
- อ่านจากข้อความด้วยกติกาภาษาไทย (เช่น "เสาร์นี้กินข้าวหกโมง", "จอดรถชั้น 3 โซน B")
- เก็บรูปได้ แต่ยังไม่อ่านตัวอักษรในรูป
- เตือนได้ตอนแอปเปิดอยู่ และกด "ลงปฏิทิน" เพื่อให้ปฏิทินเตือนแทน

## ขั้นที่ 2 — ต่อระบบอ่านรูปและการเตือนจริง (Cloudflare Worker)

ต้องมี:
- บัญชี Cloudflare (ฟรี)
- API key ของ Claude จาก console.anthropic.com (คิดเงินตามการใช้งาน ทุกครั้งที่กด "ให้ช่วยอ่าน" = 1 ครั้ง)

### 2.1 สร้างกุญแจการเตือน
ดับเบิลคลิก `worker/keygen.html` → กด **สร้างกุญแจ** → จะได้ Public key กับ Private key

### 2.2 สร้าง Worker
1. Cloudflare → **Workers & Pages** → **Create** → **Create Worker** → ตั้งชื่อ `fakjam` → Deploy
2. กด **Edit code** → ลบโค้ดเดิม → วางทั้งหมดจาก `worker/worker.js` → **Deploy**

### 2.3 สร้างที่เก็บข้อมูล (KV)
1. **Storage & Databases** → **KV** → **Create** → ชื่อ `fakjam`
2. กลับไปที่ Worker → **Settings** → **Bindings** → **Add** → **KV namespace**
   - Variable name: `KV` (ตัวพิมพ์ใหญ่)
   - KV namespace: `fakjam`

### 2.4 ใส่ค่าตั้ง
Worker → **Settings** → **Variables and Secrets** → Add

| ชื่อ | ชนิด | ค่า |
|---|---|---|
| `ANTHROPIC_API_KEY` | Secret | API key ของ Claude |
| `VAPID_PRIVATE` | Secret | Private key จาก keygen |
| `VAPID_PUBLIC` | Text | Public key จาก keygen |
| `VAPID_SUBJECT` | Text | `mailto:อีเมลของคุณ` |
| `ALLOWED_ORIGIN` | Text | `https://<ชื่อคุณ>.github.io` (ไม่มี / ท้าย ไม่มีชื่อ repo) |
| `MODEL` | Text | ไม่บังคับ ค่าเริ่มต้น `claude-sonnet-5-5` (อยากประหยัดใช้ `claude-haiku-5-5`) |
| `APP_TOKEN` | Secret | ไม่บังคับ ตั้งรหัสอะไรก็ได้ ช่วยกันการเรียกใช้แบบสุ่ม (รหัสนี้อยู่ใน index.html ด้วย คนที่เปิดดูโค้ดเว็บจึงเห็นได้) |

### 2.5 ตั้งให้เช็กทุกนาที
Worker → **Settings** → **Trigger Events** → **Add** → **Cron Triggers** → `* * * * *`

### 2.6 บอกแอปว่า Worker อยู่ไหน
เปิด `index.html` แก้บรรทัด CONFIG ด้านบนสุดของสคริปต์:

```js
const CONFIG = {
  API: "https://fakjam.<ชื่อบัญชี>.workers.dev",
  VAPID_PUBLIC: "Public key จาก keygen",
  APP_TOKEN: ""   // ใส่ให้ตรงกับ Worker ถ้าตั้งไว้
};
```

อัปโหลดทับใน GitHub แล้วรอ 1–2 นาที

## ขั้นที่ 3 — ใช้บนมือถือ

**Android (Chrome)**
เปิดเว็บ → ⚙ ตั้งค่า → **ติดตั้ง** → **เปิดการเตือน** → อนุญาต → กด **ทดสอบเตือน**

**iPhone (iOS 16.4 ขึ้นไป)**
เปิดด้วย Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** → เปิดแอปจากไอคอน → ⚙ ตั้งค่า → **เปิดการเตือน** → อนุญาต
(iPhone เปิดการเตือนได้เฉพาะตอนเปิดจากไอคอนบนหน้าจอโฮม)

## ข้อมูลอยู่ที่ไหน

- **ตั๋ว รูป โน้ต** อยู่ในมือถือเครื่องนั้นเท่านั้น (IndexedDB) ไม่ซิงก์ข้ามเครื่อง
- **Worker เก็บแค่เวลา** ที่ต้องปลุกมือถือ ไม่รู้ชื่อเรื่องหรือเห็นรูป
- **ตอนกด "ให้ช่วยอ่าน"** รูปและข้อความถูกส่งไปให้ Claude อ่าน แล้วส่งผลกลับ Worker ไม่เก็บไว้
- **ล้างข้อมูลเบราว์เซอร์ = ตั๋วหาย** ควรกด ⚙ → **สำรองเป็นไฟล์** เป็นระยะ

## ถ้ามีปัญหา

| อาการ | ตรวจ |
|---|---|
| กด "ให้ช่วยอ่าน" แล้วขึ้น "ระบบอ่านรูปไม่ตอบ" | API ใน CONFIG ถูกไหม, `ALLOWED_ORIGIN` ตรงกับเว็บไหม, ใส่ `ANTHROPIC_API_KEY` แล้วหรือยัง |
| "ต่อระบบเตือนไม่สำเร็จ" | `VAPID_PUBLIC` ใน CONFIG กับใน Worker ต้องเป็นค่าเดียวกัน และต้องผูก KV ชื่อ `KV` |
| ทดสอบเตือนแล้วไม่เด้ง | ตั้ง Cron แล้วหรือยัง, iPhone ต้องเปิดจากไอคอนหน้าจอโฮม, ปิดโหมดโฟกัส/ห้ามรบกวน |
| แก้ไฟล์แล้วแอปยังเป็นแบบเก่า | ปิดแอปแล้วเปิดใหม่ 2 ครั้ง (แอปโหลดเวอร์ชันใหม่ตอนมีเน็ต) |
| เปิด Worker URL ในเบราว์เซอร์แล้วขึ้น `origin_not_allowed` | ปกติ เพราะอนุญาตเฉพาะเว็บของคุณ |
